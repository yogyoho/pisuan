```python
            self._structured_support[model.model_name] = False
```

  5. `generalize_paragraphs`：`stats` 初始化加 `"structured": 0,`；`_record_outcome` 开头加 `if outcome.get("channel") == "structured": stats["structured"] += 1`；末尾汇总日志行补 `structured={stats['structured']}`。
