# 实体构建器 §5.2：组件拆分与脏状态守卫（2026-11-14）

依据：`docs/vibe/2026-11-14-领域实体构建器页面设计诊断.md` §5.2 前两项（组件拆分、脏状态守卫）与 §6 对应验收项。

## 目标

`DomainEntityBuilderView.vue`（1782 行）拆成「视图编排 + 6 个组件 + 1 个 composable」，并为编辑草稿补上脏状态守卫，使编辑中途切换实体/离开页面不再静默丢失修改。

## 范围

**做**

- 拆分：`EntityTree` / `EntityEditor` / `PropertyTable` / `RelationRuleEditor` / `EntityJsonModal` / `EntityExtractWizard`，页面状态收进 `composables/useEntitySchemas.js`。
- 脏状态守卫：切换实体、新建、克隆、导入、路由离开、浏览器关闭均先确认；保存成功后自动置净。
- 顺带（低成本、与守卫同源）：保存后保持当前实体选中（此前保存后 `loadData()` 会丢选中）；操作条 sticky 底部。

**不做**（仍留在 §5.2 交互重设计的后续批次）

- 属性表内联编辑与拖拽排序（`extraction_hint` 列与「进 prompt」标识已在第二批完成）。
- 删除影响面弹窗、软删/恢复。
- 分类字典表、使用情况面板、试提取（§5.3）。
- 乐观锁（并发保存冲突）：需后端版本字段，单独一批做。

## 组件边界

| 文件 | 职责 |
|---|---|
| `views/DomainEntityBuilderView.vue` | 页头、左右布局、弹窗编排、脏状态守卫、路由 query 同步 |
| `components/domain-factory/entity/EntityTree.vue` | 树 + 搜索过滤 + 计数 + 新建入口 + 删除图标 |
| `.../EntityEditor.vue` | 基础元数据卡片 + 属性表 + 关系规则 + sticky 操作条 |
| `.../PropertyTable.vue` | 属性表 + 属性编辑弹窗（含键校验） |
| `.../RelationRuleEditor.vue` | 规则列表 + 规则编辑弹窗（JSON 校验收敛在此） |
| `.../EntityJsonModal.vue` | JSON 查看/复制/下载 |
| `.../EntityExtractWizard.vue` | AI 提取两步向导（上传 → 三态结果 → 导入） |
| `composables/useEntitySchemas.js` | 数据加载、编辑副本与基线、脏状态、CRUD、树数据、值类型词表 |

规则：子组件不自行调 `load()`；写操作统一走 composable，加载后由 composable 恢复选中。

## 验收

1. 页面功能与拆分前一致（树、搜索、编辑、属性、规则、克隆、导入导出、JSON、AI 提取）。
2. 编辑任一字段后切换实体或离开路由 → 弹确认；选「继续编辑」停留且修改仍在，选「放弃修改」才切换。
3. 保存成功后 `isDirty` 为 false，且该实体仍处于选中态。
4. `web/` 下 eslint 无新增错误；`DomainEntityBuilderView.vue` 行数见上（344 行，超原 300 目标已在 checklist 说明）。
