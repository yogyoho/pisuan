## 项目定位

EAI-FLow不是单一的问答页面，而是一个面向开发者与团队的 AI 应用平台。它把知识库、知识图谱和智能体开发放在同一套系统里，适合从原型验证一路走到团队内部落地。

你可以用它完成这些事情：

- 构建面向业务场景的 RAG + 知识图谱智能体
- 将 PDF、Word、Markdown、图片等资料转为可检索、可推理的知识资产
- 基于 LangGraph v1 搭建多智能体、子智能体和工具调用流程
- 为内部系统提供可管理、可扩展的 AI 能力底座
