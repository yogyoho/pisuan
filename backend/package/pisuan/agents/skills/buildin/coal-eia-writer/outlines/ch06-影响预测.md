# 第6章 环境影响预测与评价

## 章节定位
- 依赖: 第3章环境现状（提供基线数据）、第5章影响识别（提供评价因子）、第2章规划概况（提供污染源强）
- 被依赖: 第7章承载力（提供排放数据）、第8章综合论证（提供影响结论）、第9章减缓措施（提供需减缓的影响）

## 写作要求
本章分要素预测项目建设及运营对各环境要素的影响程度和范围。
大气预测采用导则推荐模型（AERSCREEN/AREMOD），地表水采用水质模型，地下水采用数值模拟，声采用噪声衰减模型。
煤矿特色：地表沉陷预测采用概率积分法，须给出下沉值、倾斜值、水平变形值及影响范围。
每个要素须明确预测情景、预测方法、预测参数、预测结果及影响分析。

## 法规依据
- HJ 2.2-2018 大气环境（预测模式要求）
- HJ/T 2.3 地表水环境（预测模型选取）
- HJ 610-2016 地下水环境（数值模拟要求）
- HJ 2.4-2021 声环境（噪声预测公式）
- HJ 19-2022 生态影响
- 建筑物、水体、铁路及主要井巷煤柱留设与压煤开采规范（2017）（沉陷预计参数）
