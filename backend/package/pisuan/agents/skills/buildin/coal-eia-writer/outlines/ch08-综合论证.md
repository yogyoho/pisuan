# 第8章 规划方案综合论证

## 章节定位
- 依赖: 第6章影响预测（提供影响结论）、第7章承载力（提供承载力约束）
- 被依赖: 第9章减缓措施（提供需论证的方案优化方向）

## 写作要求
本章从产业政策、规划符合性、选址合理性、总平面布置合理性等角度论证项目方案的环境可行性。
须逐一对照国家产业政策、行业准入条件、区域规划，给出符合/不符合的明确判断。
选址合理性须从环境敏感目标距离、主导风向、地表水方位等角度论证。

## 法规依据

- HJ 130-2019 规划环境影响评价技术导则
