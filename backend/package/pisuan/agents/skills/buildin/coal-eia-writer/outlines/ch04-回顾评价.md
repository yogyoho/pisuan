# 第4章 回顾性评价

## 章节定位
- 依赖: 第2章规划概况（提供既有工程概况）、第3章环境现状（提供现状监测数据）
- 被依赖: 第9章减缓措施（提供"以新带老"整改方案）

## 写作要求
本章针对改扩建项目，评价既有工程的历史环境影响和环保措施效果。
须覆盖既有工程各环境要素的影响回顾、环保措施运行效果评估、遗留环境问题识别。
提出"以新带老"整改方案，作为第9章减缓措施的输入。

## 法规依据
- HJ 2.1-2016 总纲（改扩建项目回顾性评价要求）
- 环境影响评价法（改扩建项目相关规定）
