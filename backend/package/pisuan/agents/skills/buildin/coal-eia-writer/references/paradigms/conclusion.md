# 节角色范式：结论与论证收束节（conclusion）

## 适用
结论章（第十三章）的结论性小节：规划协调性分析结论、现状评价结论、环境影响评价结论、承载力分析结论、清洁生产结论、公众参与结论、综合论证结论、综合结论。
职能是把前章已得的判断按要素收拢成结论，供审批者直接引用。只收敛、不展开——每条结论必须溯源到前章依据，禁出现前章未出现的新实体、新数值、新判断（冻结铁律的反向面：结论只能收拢，不能新增）。

## 结构骨架
1. 结论先行：本节首句即给判断（「……总体可行／基本协调／不能满足……」），不铺陈背景
2. 分要素溯源：按章序逐要素收拢，每条 = 要素 + 判断 + 依据（「由表 X-X」「据第 N 章预测结果」）
3. 问题直陈：不协调项、超标项、制约因素单列成条，每条一句话点到为止，不掩饰也不重新论证
4. 收束判词：综合结论必须落到明确的可行性判断句，不留开放式结尾

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）

现状结论——
> 评价基准年，PM2.5 年均浓度不能满足《环境空气质量标准》(GB 3095-2012) 及修改单二级标准要求，其余各项指标均满足二级标准要求。

协调性结论——
> 从内部协调性来看，矿区煤炭开采与洗选加工、煤电联营、煤炭运输、供电与用电等各环节协调性较高；但也存在一定的不协调性，主要表现在：……（逐条列出不协调项）

影响结论——
> 由表 X-X 预测结果，规划实施后评价区××环境要素在……条件下……（判断），对……敏感目标的影响可以接受／不可接受。

综合结论——
> 综合规划协调性分析、环境影响预测、资源承载力与公众参与结果，从环境保护角度分析，矿区总体规划方案总体可行。

## 节尾收束段
- 「综上所述，规划方案在落实本报告提出的优化调整建议及环境影响减缓措施的前提下，从环境保护角度分析是可行的。」
（综合结论节收束句必须含明确的可行性判断，禁「仍需进一步研究」式开放收尾）

## 句式模式
- 「从……协调性来看，……较高／存在一定的不协调性，主要表现在：……」
- 「……不能满足／符合《……》（GB ……—20XX）……级标准要求」
- 「由表 X-X／据第 N 章预测结果，……可以接受／基本可控」
- 「综上所述，……从环境保护角度分析，总体可行。」

## 反模式（违反=残留门 FAIL 或缺口门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 引入前章未出现的新矿名、新数值、新标准 | 删除——结论只收拢前章已得判断 |
| 重新展开论证（方法、参数、计算过程） | 「据第 N 章预测，……」一句带过 |
| 「待确认／数据未提供」缺口散布在结论里 | 结论只写已收敛项；缺口集中到专门小节并控数量 |
| 「总体来说」「可以说」等元话语开头 | 直接以判断句开头 |
| 「本节对全书进行了总结」式自指 | 删除自指，从第一条结论写起 |
| 开放式收尾（「仍有待进一步观察」） | 落「从环境保护角度分析……可行／不可行」判词 |
