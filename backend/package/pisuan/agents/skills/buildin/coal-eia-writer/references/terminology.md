# 煤矿环评专业术语词典

> 本文件为煤矿建设项目环境影响评价核心术语简明定义，供 writer 写作时统一用词和概念参照。

## 一、评价体系总论

- **环境影响评价（EIA）**：对建设项目实施后可能造成的环境影响进行分析、预测和评估，提出预防或减轻不良环境影响的对策和措施的过程。
- **建设项目环境影响评价**：针对具体新建、改扩建项目开展的环境影响评价，区别于规划环评。
- **规划环境影响评价**：对国土空间规划、行业规划等实施后可能产生的环境影响进行评价。
- **环境影响报告书**：以书面形式对建设项目环境影响评价全过程的系统总结和成果文件。
- **环境敏感目标**：评价范围内需要特别保护的居民区、学校、医院、自然保护区、水源地等对象。
- **环境保护目标**：项目区周边需达到环境质量标准或需防止污染的敏感区域与对象的总称。
- **环境功能区划**：按环境功能要求划分的区域类别，决定该区域应执行的环境质量标准等级。

## 二、评价等级与范围

- **评价等级**：按 HJ 2.1 及各要素导则规定，根据建设项目污染物排放量、环境敏感程度等确定的分级（一级/二级/三级），决定评价深度。
- **评价范围**：建设项目环境影响评价的工作区域边界，由评价等级和导则方法确定。
- **大气环境影响评价等级**：依据估算模式（AERSCREEN）计算最大占标率分级确定。
- **地表水环境影响评价等级**：依据排放量、受纳水体规模和水质目标分级确定。
- **地下水环境影响评价等级**：依据项目地下水环境敏感程度、包气带防污性能等分级确定。
- **声环境影响评价等级**：依据建设项目所在声环境功能区类别和建设前后噪声增量确定。
- **生态环境影响评价等级**：依据项目影响范围、生物量和生态敏感性分级确定。
- **土壤环境影响评价等级**：依据项目占地规模、土壤敏感程度和功能类别分级确定。

## 三、预测与评价方法

- **AERSCREEN**：EPA 推荐的筛选级扩散模型，用于大气评价等级判定和简单浓度预测。
- **单因子指数法**：以最差因子评价环境质量的方法，公式 Ii = Ci/Si，用于地表水和土壤现状评价。
- **物料衡算法**：依据质量守恒原理计算污染物产生量和排放量的方法。
- **产排污系数**：单位产品（或原料）生产过程中污染物产生或排放的统计比值，源自手册或实测。
- **概率积分法**：用于开采沉陷预计的数学方法，基于随机介质理论计算地表变形值。
- **地表沉陷**：地下煤层开采后上覆岩层移动导致地表下陷、变形的现象。
- **环境影响识别**：通过矩阵法、清单法等识别建设项目对各环境要素的影响性质和程度。

## 四、环境质量与容量

- **环境质量标准**：为保障人群健康和生态环境安全，对环境介质中污染物限值的规定。
- **污染物排放标准**：对污染源排放污染物浓度或总量的法定限制。
- **环境容量**：在满足环境质量标准前提下，环境介质所能容纳的最大污染物负荷量。
- **环境承载力**：在不导致不可逆环境影响的前提下，区域环境系统对开发活动的支撑能力。
- **污染物排放总量控制**：对特定区域或项目的污染物排放总量设定上限的管理制度。

## 五、煤矿特定术语

- **矿井水**：煤矿开采过程中涌出的地下水，含悬浮物和可能的酸性物质，需处理达标后排放或回用。
- **煤矸石**：煤炭采掘和洗选过程中产生的伴生废石，含可燃组分，可能自燃并产生环境污染。
- **选煤厂**：对原煤进行洗选加工、去除杂质、提高煤质的设施。
- **采空区**：煤层开采后形成的空洞区域，可能导致地表沉陷和地下水漏失。
- **露天开采**：剥离表土和覆盖层后直接采煤的开采方式，生态影响范围大。
- **井工开采**：通过竖井、斜井或平硐进入地下进行采煤的方式，主要影响地表沉陷和地下水。
- **瓦斯**：煤层中赋存的以甲烷为主的可燃气体，抽采后可综合利用，直接排放造成温室效应。

## 六、管理与制度

- **清洁生产**：不断采取改进设计、使用清洁能源和原料、采用先进工艺与设备等措施，从源头削减污染、提高资源利用效率的生产模式。
- **循环经济**：以资源高效利用和循环利用为核心，以"减量化、再利用、资源化"为原则的经济模式。
- **环境风险评估**：对建设项目涉及的危险物质泄漏、火灾、爆炸等事故引发环境影响的概率和后果进行评估。
- **环境监测计划**：项目建设和运营期间对环境质量、污染源进行定期监测的方案。
- **环境管理与监测计划**：项目运营期环境保护管理体系、监测点位、因子、频次的系统安排。
- **环境影响跟踪监测**：项目建成后对实际环境影响进行的持续监测，用于验证评价结论和调整环保措施。
- **公众参与**：在环评过程中向公众公开信息、征求意见并反馈处理的法定程序。
- **"三同时"制度**：环保设施与主体工程同时设计、同时施工、同时投入运行的环境管理制度。
