# 节角色范式：减缓措施节（measures）

## 适用
生态综合整治、大气/地表水/地下水/声/固废污染防治、土壤保护、线性工程减缓、清洁生产与循环经济等措施类节。
职能是按「源项—措施—参数—主体—时序」给出可落地的措施要求，条目化表述。

## 结构骨架
1. 源项识别：「……污染物主要为……」「噪声主要来自……」
2. 措施原则：「按照……要求，基本原则为……」
3. 工程化条目：（1）（2）①②……每条含对象+具体做法+控制参数（浓度/宽度/规格/标准）
4. 管理与保障：监测、档案、监管主体、资质处置

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）

大气——
> 矿井排放大气污染物主要为物料输送、煤炭破碎筛分、临时排矸场和储运过程产生的粉尘。评价提出各煤矿产品和原煤均储存在封闭式储仓或储煤场，做到不露天、不落地、密闭贮运，禁止建设露天储煤场，并控制储煤设施周边粉尘浓度在 80 mg/m³ 之内；场内运输均采用封闭式输煤廊道，运矸车辆加装密封罩。

噪声——
> 本矿区噪声主要来自矿井主、副井提升机、通风机、水泵以及选煤厂筛分破碎设备等。噪声防治应在工程设计时将产生高强噪声的厂房车间相对集中布置或设在无人区一侧，充分利用地形地物对噪声传播的遮挡作用；在锅炉房、通风机房、洗选车间等噪声源周围以草、灌、乔搭配植树绿化，敏感区段道路两侧布设防护隔声林带。

固废——
> 矿区开发产生的固体废物按性质分为矸石、生活垃圾及水处理污泥。按照国家资源综合利用要求，固体废物综合利用和处置的基本原则为：综合利用为先，处置为后。建议各矿按要求设置危废暂存库，短期存储废矿物油等危险废物，定期交由有资质的危废处置单位处置，严禁乱堆乱放、随意排弃。

生态整治——
> 矿区开发对植被的破坏主要来自沉陷影响，植被保护措施重点在于沉陷区治理：对沉陷区及时进行充填裂缝、回填塌陷坑、覆土平场、撒播草籽；对可能受到严重破坏的基本农田集中分布区，采取充填开采等保护性开采措施；工业场地周边布置 20 m～40 m 宽防护林带，做到林草结合、乔灌搭配。

施工期——
> 施工期针对水土流失采取的措施主要有：①排水措施：在路基、路面设置排水沟、截水沟、拦水带等排水设施；②边坡防护：在边坡上种草或铺草皮；③划定施工道路宽度红线，尽量缩小施工范围，不得随意开辟施工道路，施工完成后尽快实施植被恢复。

## 节尾收束段
- 「矿区须在典型区域设置岩移观测站，长期动态观测采煤后地表沉陷相关参数；对植被覆盖度、植物种类、生物多样性等指标进行定期评估，对指标不达标区域进行补植补播，并建立沉陷影响调查档案。」
- 「为防止事故状态下外排，各选煤厂须设立事故浓缩池等事故处理设施，杜绝事故排放。」

## 句式模式
- 「……污染物主要为……／噪声主要来自……」（源项识别）
- 「评价提出……做到……，禁止……，并控制……浓度在 X 之内」
- 「按照……要求，基本原则为：……」
- 「①……②……③……」（同一条措施内的工程分解）
- 「建议……设置……，定期……，交由有资质的单位处置，严禁……」

## 反模式（与残留门词表同源；违反=残留门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 「本节提出如下减缓措施」 | 直接条目化给出措施 |
| 「表单直出的措施清单如下」 | 「措施汇总见表 X」 |
| 「登记表单中的治理要求包括」 | 直接写措施内容与参数 |
| 「衔接义务：措施应与影响章节一一对应」 | 删除——措施直接指明针对的影响对象 |
