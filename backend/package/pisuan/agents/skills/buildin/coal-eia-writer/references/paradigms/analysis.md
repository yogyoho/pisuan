# 节角色范式：影响预测与评价节（analysis）

## 适用
规划实施影响预测与评价主体节：沉陷、生态、地表水、地下水、大气、声、固废、土壤、敏感目标、社会环境、资源环境承载力、规划方案综合论证等。
职能是给出「影响机理—预测设置—预测结果—对照标准—评价结论」的完整链条，以评价结论收尾并指向措施。

## 结构骨架
1. 影响机理引入：「由环境影响识别可知，……主要影响因子为……」
2. 预测情景/方法设置：「本次评价根据……设置 N 个预测情景……详见表 X」
3. 分要素预测：现状参数 → 预测模式 → 结果（数值与范围）
4. 叠加敏感目标：与保护目标的距离、影响半径、受影响程度
5. 评价结论并指向措施：「本次评价提出了相应的……措施/建议」

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）

情景设置——
> 本次评价根据矿区规划及矿区资源环境条件设置 2 个预测情景：情景 1 为规划方案，情景 2 为环境约束条件下优化调整后的环评推荐方案，并对两种情景下规划实施的环境影响进行评价。情景一、二具体内容详见表 6-1。

机理引入——
> 由环境影响识别可知，矿区生态类影响的主要因子为井工矿采空区塌陷所致的地表沉陷，其影响具有多层次和多方面、直接和间接作用的特征。在进行矿区规划环境影响预测与评价之前，应首先分析矿区采煤沉陷特点，为生态环境、水环境及社会环境影响分析与评价提供基础。

预测评价——
> 矿区内地貌类型主要为低山丘陵地貌，矿区以井工矿开采为主。矿区开发时露天矿采掘场挖损、外排土场压占以及井工矿开采造成的地表沉陷，均会对区域地形地貌造成影响。根据沉陷预测结果，全部可采煤层开采后，预计最终地表沉陷影响范围约 120 km²，最大下沉值出现在中深部采区。

敏感目标叠加——
> 矿区西侧与某国家级自然保护区的最近距离为 2.1 km，其中距保护区最近的井田开发对煤系地层含水层的疏干影响半径最大预计可达 4.4 km，已扩展到保护区实验区，可能影响区内植被生长，评价据此提出禁采与保护煤柱留设要求。

社会影响——
> 矿区规划方案实施对当地社会经济的影响利弊并存。有利影响主要表现在促进当地经济发展，改善区域基础设施，增加区域经济收入，增加当地群众就业机会；不利影响主要表现在采煤沉陷造成矿区林草地、耕地破坏，采取土地生态恢复治理、补偿等措施可减缓这种不利影响。

## 节尾收束段
- 「矿区为多煤层开采，随着开采面积的扩大、开采时间的延长，沉陷区面积将逐渐扩大，开采沉陷的影响也将逐渐加大。本次评价提出了相应的生态恢复与修复治理措施：开采过程中对沉陷区及时充填裂缝、回填塌陷坑、覆土平场、撒播草籽，恢复植被。」
- 「本次评价提出对上述主要河流矿区段留设保护煤柱，规划范围与水源地重叠区划为禁采区并留设保护煤柱；开发过程中应加强对地表水及含水层的监测，定期评估煤矿开发对水环境的影响。」
- 「由表 X 可知，若矿区能够严格按照总体规划及本报告提出的环境保护要求安排生产，矿区规划的环境影响评价指标是可达的。」

## 句式模式
- 「由环境影响识别可知，……主要影响因子为……」
- 「根据……预测结果，……预计……」
- 「与……（保护目标）最近距离 X km，……影响半径最大预计可达 X km，可能影响……」
- 「利弊并存。有利影响主要表现在……；不利影响主要表现在……」
- 「本次评价提出了相应的……措施/建议」

## 反模式（与残留门词表同源；违反=残留门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 「本节的预测思路是先……再……」 | 直接从影响机理写起 |
| 「冻结槽位的预测值如下」 | 「预测结果见表 X」 |
| 「其下游用途是为减缓措施章提供依据」 | 删除——以「本次评价提出了相应的……措施」收尾即完成指向 |
| 「直渲的预测结果如下」 | 「预测结果见表 X」 |
| 「本节与第 9 章的分工边界是……」 | 删除，直接给出措施指向 |
