# 节角色范式：章首定位节（opener）

## 适用
总则章及各章首节：交代评价对象、依据、范围、时段、标准、保护目标、重点与方法。
职能是向审批机关交代「评什么、凭什么评、怎么评」。全部为结论性陈述，不解释本节怎么写。

## 结构骨架
1. 对象与任务来源：批复/委托文号、规划修编缘由、开发现状
2. 评价目的与原则：预防不良环境影响 + 布局/规模/时序在承载能力内有序发展
3. 评价范围/时段/分区：导则依据 + 「见表 X」
4. 环境功能区划与标准、保护目标清单：现场踏勘调查 + 「详见表 X 及图 X」
5. 评价重点与方法、工作程序：逐条列出 + 方法表 + 技术路线图引用

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）

任务由来——
> 某矿区开发时间较早，2005 年国家发展和改革委员会以《关于该矿区总体规划的批复》对总体规划进行批复，矿区划分为 4 个井田开发，规划面积约 500 km²，规划建设总规模 10.0 Mt/a。规划实施至今，矿区内生产矿井规模与原规划相比均有变化，矿区煤炭开发总规模已超出原规划规模。按照煤炭矿区总体规划管理规定，属于规划重大调整情形，需开展总体规划修编环境影响评价。

评价目的——
> 实施可持续发展战略，在矿区总体规划编制和决策过程中，充分考虑规划实施可能涉及的环境问题，预防规划实施后可能造成的不良环境影响，合理安排煤炭生产力的布局、开采顺序以及开发规模，使煤炭开采在资源、环境承载能力的基础上有序、和谐发展。

保护目标——
> 根据《规划环境影响评价技术导则 总纲》（HJ 130-2019）中关于生态敏感区（点）的定义，结合矿区及周边的自然环境与人文特征，经现场踏勘和调查分析，评价区主要环境保护目标有周边国家级自然保护区、基本农田、地表水体、水源保护地、铁路与公路、城镇及文物等，详见表 1-1 及图 1-1。

评价重点——
> 结合本规划内容和区域环境特征，确定本评价重点如下：（1）矿区开发历史较长，采煤沉陷等生态环境问题已有显现，评价对已开采区进行回顾性评价，分析现存生态和环境问题，提出相应的保护措施和方案，作为后续开发的借鉴。

## 节尾收束段
- 「根据《规划环境影响评价技术导则 总纲》（HJ 130-2019）推荐的工作程序，结合煤炭行业环评特点，确定本次评价工作程序见图 1-2。」
- 「拟采用现场调查与监测法、资料分析法、类比分析法、模型法、情景分析法、环境承载力分析法等方法开展评价工作，主要评价环节和要素的评价方法见表 1-2。」

## 句式模式
- 「2005 年，国家发展和改革委员会以（文号）批复了《……总体规划》」
- 「依据相应环境影响评价技术导则和规范要求，确定本次评价各要素评价范围见表 X」
- 「经现场踏勘和调查分析，评价区主要环境保护目标有……」
- 「结合本规划内容和区域环境特征，确定本评价重点如下：」
- 「本次评价以 2022 年为评价基准年」

## 反模式（与残留门词表同源；违反=残留门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 「本节回答的是评价范围问题」 | 直接给出：「依据导则要求，确定各要素评价范围见表 X」 |
| 「其上游依据为批复文件」 | 「根据（文号）批复……」 |
| 「就任务性质而言，本节属于……」 | 删除，直接陈述对象与任务 |
| 「各项依据不作任何改写、逐字呈现」 | 「编制依据见表 X」 |
| 「凡本节叙述所需而登记资料未予涵盖者……」 | 直接按已确认依据陈述 |
