# 节角色范式：程序与过程节（process）

## 适用
程序合规叙事节：公众参与（第十二章）的调查过程、意见统计与处理，环境管理与监测计划（第十章）的组织安排与执行程序。
职能是交代法定程序的履行过程：依据—时间—对象—方式—结果—回应。程序节的价值在可核查，不在论证。

## 结构骨架
1. 程序依据：依据的规定／导则／地方要求（引标准文号）
2. 过程叙事：何时—以何种方式—向何对象—开展了什么（两次公示、问卷、座谈）
3. 结果统计：意见数量与分类一律进表格（{{TABLE: 族}} 直渲），代表性意见摘录引述
4. 回应处理：采纳／部分采纳／不采纳及理由，采纳意见落实到规划优化或措施调整

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）
> 依据《环境影响评价公众参与办法》（生态环境部令 第 4 号），建设单位于 X 年 X 月 X 日至 X 月 X 日在××网站进行了首次信息公示，公示期 10 个工作日；……共发放调查问卷 X 份，回收有效问卷 X 份，有效回收率 X%。

## 节尾收束段
- 「公众参与调查显示，多数公众支持规划实施，未收到反对意见；公众提出的××意见已在规划优化调整中予以落实。」

## 句式模式
- 「依据《……》（××令 第 X 号），于 X 年 X 月进行了……公示」
- 「共发放调查问卷 X 份，回收有效问卷 X 份，有效回收率 X%」
- 「对公众提出的……意见，采纳 X 条、部分采纳 X 条、不采纳 X 条」
- 「监测频次为……，执行《……》相应要求」

## 反模式（违反=残留门 FAIL 或缺口门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 「公众参与十分重要，应高度重视」类泛论 | 删除——程序节只写履行过程与结果 |
| 意见统计写成散文段落 | 逐条意见与回应进表格（{{TABLE: 族}}） |
| 编造问卷数字、公示日期 | 缺数标「[待确认]」，禁虚构 |
| 「大部分群众都表示满意」无统计支撑 | 给数量与占比（来自冻结数据） |
