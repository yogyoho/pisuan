# 煤矿环评报告各章节编写指南

> 基于 HJ/T 130-2019《建设项目环境影响报告表（书）编制技术导则》及横城矿区环评报告结构，对 13 章逐一给出编写要点与格式示例。

---

## 第1章 总论

### 编写要点
- 明确评价目的、编制依据（法律法规、技术导则、项目文件）
- 筛选评价标准（环境质量标准、污染物排放标准）
- 确定评价等级和评价范围（各环境要素分别说明）
- 识别环境敏感目标，列表说明保护级别和相对位置

格式示例：
```
1.1 评价目的
1.2 编制依据
  1.2.1 法律法规
  1.2.2 技术导则
  1.2.3 项目文件
1.3 评价标准
  1.3.1 环境质量标准
  1.3.2 污染物排放标准
1.4 评价等级及评价范围
  1.4.1 大气环境
  1.4.2 地表水环境
  1.4.3 地下水环境
  1.4.4 声环境
  1.4.5 生态环境
1.5 环境敏感目标
```

---

## 第2章 规划概况

### 编写要点
- 介绍矿区/井田规划背景、开发性质（新建/改扩建）
- 说明建设规模（产能 Mt/a）、服务年限、开采方式（井工/露天）
- 描述矿区总平面布置、工业场地、运输系统
- 列出主要技术经济指标

格式示例：
```
2.1 矿区总体规划概况
2.2 本项目概况
  2.2.1 项目名称及建设性质
  2.2.2 建设规模与服务年限
  2.2.3 开采方式与工艺
2.3 总平面布置
2.4 主要技术经济指标
```

表格格式：
| 序号 | 项目 | 单位 | 数值 | 备注 |
|------|------|------|------|------|
| 1 | 井田面积 | km² | XX | |
| 2 | 设计生产能力 | Mt/a | XX | |

## 第3章 环境现状调查与评价

### 编写要点
- 基于现场监测数据，系统阐述区域自然环境质量现状
- 须覆盖大气/地表水/地下水/声/土壤/生态六个要素
- 每个要素：监测布点 → 监测因子 → 评价标准 → 现状值 → 达标分析
- 生态现状需说明土地利用类型、植被覆盖度、生物量

格式示例：
```
3.1 自然环境概况
  3.1.1 地理位置
  3.1.2 地形地貌
  3.1.3 气候气象
3.2 环境质量现状监测与评价
  3.2.1 大气环境现状
    （监测点位图、监测因子、监测时段、评价方法）
  3.2.2 地表水环境现状
  3.2.3 地下水环境现状
  3.2.4 声环境现状
  3.2.5 土壤环境现状
3.3 生态环境现状
```

## 第4章 回顾性评价

### 编写要点
- 针对改扩建项目，评价既有工程的环境影响历史
- 分析既有环保措施及运行效果
- 识别遗留环境问题，提出"以新带老"整改方案

格式示例：
```
4.1 既有工程概况
4.2 既有工程环境影响回顾
  4.2.1 大气环境影响
  4.2.2 水环境影响
  4.2.3 生态影响
4.3 既有环保措施及效果评估
4.4 存在的环境问题及整改方案
```

---

## 第5章 环境影响识别与评价因子筛选

### 编写要点
- 采用矩阵法或清单法识别各环境要素的影响性质（有利/不利、可逆/不可逆）
- 筛选评价因子（现状评价因子、预测评价因子）
- 确定重点评价要素

格式示例：
```
5.1 环境影响识别
  （影响识别矩阵表：工程活动 × 环境要素）
5.2 评价因子筛选
  5.2.1 现状评价因子
  5.2.2 预测评价因子
5.3 重点评价要素确定
```

---

## 第6章 环境影响预测与评价

### 编写要点
- 分要素预测：大气（AERSCREEN/导则推荐模型）、地表水（水质模型）、地下水（数值模拟）、声（噪声衰减模型）、生态（沉陷预计）
- 每个要素：预测情景 → 预测方法 → 预测结果 → 影响分析
- 矿井沉陷预测用概率积分法，给出下沉值、倾斜值、水平变形值

格式示例：
```
6.1 大气环境影响预测
  6.1.1 预测模式与参数
  6.1.2 预测结果及分析
6.2 地表水环境影响预测
6.3 地下水环境影响预测
6.4 声环境影响预测
6.5 地表沉陷预测
  6.5.1 预测方法（概率积分法）
  6.5.2 预测参数
  6.5.3 沉陷预测结果
6.6 生态环境影响预测
```

## 第7章 环境承载力分析

### 编写要点
- 分析区域水资源承载力（可供水量 vs 需水量）
- 分析大气环境容量（A值法计算）
- 分析水环境容量（河流段容量计算）
- 评估项目排放对区域承载力的占用比例

格式示例：
```
7.1 水资源承载力分析
7.2 大气环境容量分析
7.3 水环境容量分析
7.4 承载力综合评估
```

---

## 第8章 规划方案综合论证

### 编写要点
- 论证项目与产业政策、规划符合性
- 论证选址/选线环境合理性
- 论证总平面布置环境合理性
- 提出规划方案优化建议

格式示例：
```
8.1 与产业政策符合性分析
8.2 与相关规划符合性分析
8.3 选址环境合理性分析
8.4 总平面布置合理性分析
8.5 规划方案优化建议
```

---

## 第9章 环境保护措施及其可行性论证

### 编写要点
- 分要素提出减缓措施：大气（除尘/脱硫）、水（矿井水处理/生活污水处理）、声（隔声降噪）、生态（沉陷区治理/土地复垦）、固废（矸石处置）
- 每项措施说明技术可行性、经济合理性、达标可靠性
- 给出环保投资估算表

格式示例：
```
9.1 大气污染防治措施
9.2 水污染防治措施
  9.2.1 矿井水处理
  9.2.2 生活污水处理
9.3 噪声控制措施
9.4 固体废物处置措施
  9.4.1 煤矸石处置
  9.4.2 其他固废
9.5 生态保护与恢复措施
  9.5.1 沉陷区治理
  9.5.2 土地复垦
9.6 环保投资估算
```

## 第10章 环境管理与监测计划

### 编写要点
- 建立环境管理体系（机构、职责、制度）
- 制定施工期和运营期环境监测计划
- 明确排污口规范化要求
- 制定环境风险应急预案

格式示例：
```
10.1 环境管理机构及职责
10.2 环境管理制度
10.3 环境监测计划
  10.3.1 施工期监测
  10.3.2 运营期监测
10.4 排污口规范化
10.5 环境风险应急预案
```

表格格式：
| 监测要素 | 监测点位 | 监测因子 | 监测频次 | 执行标准 |
|----------|----------|----------|----------|----------|
| 大气 | XX点 | PM10/SO2/NOx | 季度 | GB3095 |

## 第11章 清洁生产与循环经济

### 编写要点
- 采用 HJ 446 等行业清洁生产标准进行分级评价
- 评价六指标：生产工艺与装备、资源能源利用、污染物产生、废物回收利用、环境管理、产品
- 分析矿井水回用、矸石综合利用等循环经济方案

格式示例：
```
11.1 清洁生产评价
  11.1.1 评价指标体系
  11.1.2 评价结果
11.2 循环经济分析
  11.2.1 矿井水综合利用
  11.2.2 煤矸石综合利用
  11.2.3 瓦斯抽采利用
11.3 清洁生产改进建议
```

## 第12章 公众参与

### 编写要点
- 说明公众参与方式（问卷调查、座谈会、公示等）
- 统计公众意见，分类汇总
- 对公众关切问题逐一回应
- 说明意见采纳情况

格式示例：
```
12.1 公众参与方式
12.2 公示情况
  12.2.1 第一次公示
  12.2.2 第二次公示
12.3 问卷调查

  12.3.2 调查结果统计
12.4 公众意见汇总及回应
12.5 意见采纳情况
```

## 第13章 环境影响评价结论

### 编写要点
- 概括各要素环境影响评价主要结论
- 明确项目环境可行性结论（可行/有条件可行/不可行）
- 列出环保措施和达标情况
- 给出总量控制指标

格式示例：
```
13.1 项目概况及主要环境影响
13.2 环境质量现状结论
13.3 环境影响预测结论

13.5 清洁生产结论
13.6 总量控制指标
13.7 公众参与结论
13.8 综合评价结论
```

## 编写注意事项

1. **数据可追溯**：所有数值须标注来源（监测报告、设计文件、产排污系数手册）
2. **标准时效性**：引用最新版本标准，注明标准号和年份
3. **占位符规范**：缺失数据用 `{{MISSING:数据名称}}`，章间引用用 `{{REF:chXX/表X-Y}}`
4. **图表编号**：全文图表统一编号，表 X-Y、图 X-Y（X=章号，Y=序号）
5. **定量优先**：预测结论须给出数值和达标判断，避免"影响较小"等模糊表述
