# 煤矿环评报告标准13章结构

> 当图谱查询不可用时，本文件作为 fallback 提供煤矿环评报告的标准章节结构。
> 依据 HJ/T 130-2019 及横城矿区环评报告整理。

## 13章结构总表

| 章号 | 标题 | 主要内容 | 数据来源 |
|------|------|----------|----------|
| 1 | 总论 | 评价目的、编制依据、评价标准、评价等级与范围、环境敏感目标 | 法规库、项目可研、各要素导则 |
| 2 | 规划概况 | 矿区总体规划、项目概况（规模/方式/年限）、总平面布置、技术经济指标 | 项目可研、设计文件 |
| 3 | 环境现状调查与评价 | 自然环境概况、大气/地表水/地下水/声/土壤/生态现状监测与评价 | 现场监测报告、遥感数据 |
| 4 | 回顾性评价 | 既有工程环境影响回顾、环保措施效果评估、遗留问题整改 | 改扩建项目历史数据 |
| 5 | 环境影响识别与评价因子筛选 | 影响识别矩阵、评价因子筛选、重点要素确定 | 工程分析、导则要求 |
| 6 | 环境影响预测与评价 | 大气/水/地下水/声/沉陷/生态预测，各要素影响分析 | 模型计算、产排污系数 |
| 7 | 环境承载力分析 | 水资源承载力、大气/水环境容量、综合评估 | 区域水资源公报、模型计算 |
| 8 | 规划方案综合论证 | 产业政策符合性、规划符合性、选址合理性、优化建议 | 政策文件、区域规划 |
| 9 | 环境保护措施及可行性论证 | 各要素减缓措施、技术经济可行性、环保投资估算 | 环保工艺设计、投资概算 |
| 10 | 环境管理与监测计划 | 管理体系、施工期/运营期监测计划、应急预案 | 监测规范、风险管理导则 |
| 11 | 清洁生产与循环经济 | 清洁生产评价、矿井水/矸石/瓦斯综合利用、改进建议 | HJ 446 清洁生产标准 |
| 12 | 公众参与 | 公示、问卷调查、意见汇总与回应、采纳情况 | 公众参与调查表 |
| 13 | 环境影响评价结论 | 各要素结论汇总、可行性结论、总量指标 | 前序各章结论 |

## 分层加载顺序

```
1. 图谱查询（首选）→ ChapterTemplate + ParagraphTemplate + Slot
2. 本文件 report_structure.md（图谱不可用时 fallback）
3. outlines/chXX.md（章节级静态骨架）
```

## 各章依赖关系

```
第1章总论 ←── 第2章规划概况（提供项目基本信息）
第3章环境现状 ──→ 第6章影响预测（提供基线数据）
第5章影响识别 ──→ 第6章影响预测（提供评价因子）
第6章影响预测 ──→ 第7章承载力（提供排放数据）
第6章影响预测 ──→ 第8章综合论证（提供影响结论）
第6章影响预测 ──→ 第9章减缓措施（提供需减缓的影响）
第2~9章 ──→ 第13章结论（汇总前序结论）
```

## 章节分配与 writer 角色映射

| writer 角色 | 负责章节 | 依赖前置章 |
|-------------|----------|------------|
| regulation-writer | 1、10、11、12 | 无（独立章节） |
| data-survey-writer | 2、3、4 | 无 |
| prediction-writer | 5、6、7、8、9、13 | 第3章（基线）、第5章（因子） |
