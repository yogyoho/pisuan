# 节角色范式：现状与概况节（baseline）

## 适用
区域自然与社会经济概况、环境质量与生态现状调查评价、回顾性评价类节。
职能是把区域客观条件与监测调查结果陈述清楚，为影响预测提供本底。以数据和事实为主语，不作过程说明。

## 结构骨架
1. 区位与地貌：位于……地势……属……地貌，海拔标高 X～X m，相对高差 X m
2. 气候气象：属……气候，年均气温/降水量/蒸发量/主导风向
3. 水系、土壤、植被分述：按要素逐项给出类型与分布
4. 现状监测：数据来源（例行监测/委托补充监测）+ 监测时间与点位
5. 现状评价结论：综上所述……稳定程度……因此应及时采取……

## 范文（去实体化，仅示范句法与信息组织；实体与数值一律替换为本项目冻结值）

地形地貌——
> 矿区位于某高原东南部，具典型的黄土塬区地形地貌特征，主要由黄土梁、峁、塬、坡、沟谷等组成，地形复杂。地势北高南低、西高东低，海拔 900 m～1450 m，地形起伏大，相对高差 200 m～424 m，一般塬面和沟底高差 240 m～300 m。

气候——
> 本区气候区划属温带半湿润大陆性气候区，四季分明，大陆性气候显著。年降水量 330 mm～900 mm，平均 580 mm，七、八、九 3 个月降水量占全年的 55%；年蒸发量 1040 mm～1790 mm，年平均蒸发量 1400 mm。

区位交通——
> 规划矿区位于某盆地北部，行政区划隶属周边两县（市）管辖，距区域中心城市约 35 km。矿区向南经干线公路可达周边城市，向北经干线公路可达主要工业区；现有国道从矿区东部通过，各井田均有公路与其相接，交通尚属方便。

生态现状结论——
> 综上所述，评价区生态系统的生产力较低，以森林和农田生态系统为主，区域植被类型较为简单，评价区生态系统结构与功能较完整，但稳定程度一般，容易受人为和外界环境干扰而发生水土流失。煤矿开发利用的同时，应及时采取土地复垦措施，通过人工恢复和自然演替恢复植被覆盖度和生物量，逐渐恢复和提高生态系统的稳定性和完整性。

## 节尾收束段
- 「评价区生态环境状况各项评价指标水平均比较稳定，无明显变化。但生态系统整体还比较脆弱，植被覆盖度仍处于一般水平，土地生产力水平不高，区域生态环境保护形势依然严峻。」
- 「通过上表可知，Shannon-Weaver 多样性指数（H）为 1.39，占该理论上限的 77.4%，说明评价范围内群落多样性程度较高。」

## 句式模式
- 「矿区位于……，行政区划隶属……管辖」
- 「地势……高……低，海拔标高一般为 X m～X m，一般相对高差 X m～X m」
- 「本区气候区划属……气候区，……。年均降水量……，年平均蒸发量……」
- 「本次评价收集该区域环境质量现状数据，同时委托专业机构对评价区环境空气、地表水、地下水、声环境、土壤环境质量进行了补充监测，监测时间为 2024 年 7 月」
- 「根据……监测结果，各监测点……表现为……」

## 反模式（与残留门词表同源；违反=残留门 FAIL）
| 禁止写法 | 改成 |
|---|---|
| 「本节收集整理了区域概况资料」 | 直接从区位与地貌写起 |
| 「表单直出的监测值如下」 | 「各监测点监测结果见表 X」 |
| 「登记口径的土壤含盐量为……」 | 「各监测点土壤含盐量为 X g/kg」 |
| 「其下游用途是为第 6 章预测提供本底」 | 删除——预测章自会引用本节结论 |
