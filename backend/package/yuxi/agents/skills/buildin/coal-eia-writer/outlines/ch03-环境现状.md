# 第3章 环境现状调查与评价

## 章节定位
- 依赖: 第2章规划概况（提供项目地理位置和评价范围）
- 被依赖: 第6章影响预测（提供基线数据）、第7章承载力（提供环境质量现状）

## 写作要求
本章基于现场监测数据，系统阐述区域自然环境质量现状。
须覆盖大气/地表水/地下水/声/土壤/生态六个要素，每个要素按"监测布点→监测因子→评价标准→现状值→达标分析"流程展开。
生态现状需说明土地利用类型、植被覆盖度、生物量、敏感生态区域。

## 法规依据
- HJ 2.2-2018 环境影响评价技术导则 大气环境
- HJ/T 2.3 地表水环境
- HJ 610-2016 地下水环境
- HJ 2.4-2021 声环境
- HJ 964-2018 土壤环境
- HJ 19-2022 生态影响
- GB 3095-2012 环境空气质量标准
- GB 3838-2002 地表水环境质量标准
- GB/T 14848-2017 地下水质量标准
- GB 3096-2008 声环境质量标准

## 数据需求清单
- [ ] 大气监测: PM10/SO2/NO2/TSP/PM2.5（各点位连续7天）
- [ ] 地表水监测: pH/COD/氨氮/SS/石油类等（断面水质）
- [ ] 地下水监测: pH/总硬度/硫酸盐/溶解性总固体等
- [ ] 声环境监测: 厂界及敏感点噪声值
- [ ] 土壤监测: 重金属/石油烃等
- [ ] 生态调查: 土地利用类型/植被类型/生物量
