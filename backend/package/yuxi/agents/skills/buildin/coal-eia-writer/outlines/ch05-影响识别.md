# 第5章 环境影响识别与评价因子筛选

## 章节定位
- 依赖: 第2章规划概况（提供工程污染源分析）
- 被依赖: 第6章影响预测（提供评价因子）、第9章减缓措施（提供重点影响要素）

## 写作要求
本章通过系统识别建设项目对各环境要素的影响性质和程度，筛选出现状评价因子和预测评价因子。
须采用矩阵法或清单法，覆盖施工期和运营期两个阶段。
明确重点评价要素，为第6章预测指明方向。

## 法规依据
- HJ 2.1-2016 总纲（环境影响识别方法）
- HJ 19-2022 生态影响（生态影响识别）
