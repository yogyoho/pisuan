# 第11章 清洁生产与循环经济

## 章节定位
- 依赖: 第2章规划概况（提供工艺/资源消耗数据）、第9章减缓措施（提供废物综合利用方案）
- 被依赖: 第13章结论（汇总清洁生产水平）

## 写作要求
本章采用行业清洁生产标准对项目进行分级评价，须覆盖六大指标体系。
煤矿特色：矿井水回用率、矸石综合利用率、瓦斯抽采利用率是循环经济核心指标。
须提出清洁生产改进建议，指明提升方向。

## 法规依据
- HJ 446-2008 清洁生产标准 煤炭采选业
- 中华人民共和国清洁生产促进法
- 中华人民共和国循环经济促进法
