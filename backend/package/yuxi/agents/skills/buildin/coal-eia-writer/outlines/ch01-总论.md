# 第1章 总论

## 章节定位
- 依赖: 无（首章，为全报告奠定评价基础）
- 被依赖: 第2章规划概况（需引用评价范围）、后续各章（需引用评价标准与等级）

## 写作要求
本章为全报告总纲，须明确评价目的、法律依据、适用标准、评价等级与范围、敏感目标。
编制依据须覆盖法律法规、技术导则、项目文件三个层次，评价标准须区分质量标准与排放标准。
评价等级按各要素导则方法逐一确定，评价范围配以图示说明。

## 法规依据
- HJ 2.1-2016 建设项目环境影响评价技术导则 总纲
- HJ 2.2-2018 环境影响评价技术导则 大气环境
- HJ/T 2.3 地表水环境
- HJ 610-2016 地下水环境
- HJ 2.4-2021 声环境
- HJ 19-2022 生态影响
- HJ 964-2018 土壤环境
- HJ 130-2019 规划环境影响评价技术导则 总纲

## 写作骨架
1.1 评价目的
1.2 编制依据（法律法规/技术导则/项目文件）
1.3 评价标准（环境质量标准/污染物排放标准）
1.4 评价等级及评价范围（各要素分述）
1.5 环境敏感目标（列表+图示）
1.6 评价工作程序
