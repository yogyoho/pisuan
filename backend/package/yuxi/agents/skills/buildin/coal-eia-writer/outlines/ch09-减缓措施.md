# 第9章 环境保护措施及其可行性论证

## 章节定位
- 依赖: 第6章影响预测（提供需减缓的影响）、第8章综合论证（提供方案优化建议）
- 被依赖: 第10章环境管理（提供需监测的措施）、第13章结论（汇总措施效果）

## 写作要求
本章分要素提出环境保护减缓措施，每项措施须说明技术可行性、经济合理性、达标可靠性。
煤矿特色措施：矿井水处理（沉淀+过滤+消毒后回用）、煤矸石处置（井下充填/地面堆放+综合利用）、沉陷区治理（填堵/复垦/生态恢复）。
须给出环保投资估算表和措施汇总表。

## 法规依据
- 煤炭工业污染物排放标准 GB 20426-2006
- HJ 2.1-2016 总纲（环保措施要求）
- 煤矸石综合利用管理办法
- 土地复垦条例
