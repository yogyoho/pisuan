# 第2章 规划概况

## 章节定位
- 依赖: 第1章总论（提供评价范围界定）
- 被依赖: 第3章环境现状（提供项目地理位置）、第6章影响预测（提供工程污染源分析）

## 写作要求
本章介绍矿区/井田规划背景及本项目工程概况，须覆盖建设规模、开采方式、服务年限、总平面布置、工艺流程。
污染源分析须给出大气/水/噪声/固废各要素的产排污节点和排放量，为后续预测提供源强数据。

## 法规依据
- 煤炭工业矿井设计规范 GB 50215-2005
- 煤矿安全规程
- HJ 2.1-2016 总纲（工程分析要求）
