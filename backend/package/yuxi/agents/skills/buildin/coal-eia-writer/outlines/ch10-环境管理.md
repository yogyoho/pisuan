# 第10章 环境管理与监测计划

## 章节定位
- 依赖: 第9章减缓措施（提供需监测的措施）、第6章影响预测（提供需跟踪的预测结论）
- 被依赖: 第13章结论（汇总管理要求）

## 写作要求
本章建立项目全生命周期环境管理体系，须覆盖施工期和运营期。
监测计划须明确监测要素、监测点位、监测因子、监测频次和执行标准。
须制定环境风险应急预案，明确风险源、应急组织、响应程序。

## 法规依据
- HJ 2.1-2016 总纲（环境管理与监测要求）
- 排污许可管理办法
- 突发环境事件应急预案管理办法
- HJ 169-2018 建设项目环境风险评价技术导则
