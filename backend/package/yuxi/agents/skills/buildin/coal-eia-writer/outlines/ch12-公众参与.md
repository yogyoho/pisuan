# 第12章 公众参与

## 章节定位
- 依赖: 第2章规划概况（提供项目基本信息）、第9章减缓措施（提供环保措施信息）
- 被依赖: 第13章结论（汇总公众参与结论）

## 写作要求
本章记录环评过程中公众参与的组织实施情况及结果。
须覆盖两次公示、问卷调查、座谈会等参与方式。
对公众意见分类汇总，逐一回应，说明采纳情况。反对意见须重点回应。

## 法规依据
- 环境影响评价法（公众参与条款）
- 环境影响评价公众参与办法（生态环境部令第4号）
- 环境保护部公告（公示格式要求）
