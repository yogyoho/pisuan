# 第13章 环境影响评价结论

## 章节定位
- 依赖: 前序所有章节（第1~12章的结论汇总）
- 被依赖: 无（终章，交付给决策者）

## 写作要求
本章是全报告的结论汇总，须简洁明确，每条结论给出定性+定量判断。
最终须给出项目环境可行性结论：可行/有条件可行/不可行。
总量控制指标须明确到具体污染物和吨/年数值。

## 法规依据
- HJ 2.1-2016 总纲（结论要求）
- 主要污染物总量控制管理办法

## 写作骨架
13.1 项目概况及主要环境影响
  （项目名称/规模/工艺 + 各要素主要影响概述）
13.2 环境质量现状结论
  （各要素现状达标情况）
13.3 环境影响预测结论
  （各要素预测最大影响值及达标情况）
13.4 环保措施结论
  （措施可行性 + 达标可靠性）
13.5 清洁生产结论
  （清洁生产等级 + 循环经济水平）
13.6 总量控制指标
  （COD/氨氮/SO2/NOx 等总量建议值）
13.7 公众参与结论
  （支持率 + 反对意见处理情况）
13.8 综合评价结论
  （项目环境可行性判断）
